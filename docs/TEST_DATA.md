# 实机测试：需要保留哪些数据

[文档导航](README.md) · [离线辨识](IDENTIFICATION.md) · [4310 辨识](DM4310_IDENTIFICATION.md)

**先保存原始反馈、目标、最终命令和实验配置，再生成分析数据。** 本页已对照现有双 GM6020 云台旧工程的实际赋值与发送路径，区分已经输出的数据、MCU 内已有但尚未导出的数据，以及需要标定或新增测量才能得到的数据。Yaw 可连续旋转，Pitch 为折叠机构。

本页和[空白模板](templates/test_data/README.md)是采集约定，**没有给旧工程新增记录器或改变通信协议**。现有 USB 可以先留存姿态数据；完整控制对比需要增加少量记录点，动力学辨识还需要力矩标定和时间对齐。4310 使用独立的[采集与辨识说明](DM4310_IDENTIFICATION.md)，不能直接套旧工程的 GM6020 反馈格式。

## 1. 旧工程现在能得到什么

已核对的旧工程中，Yaw 接 CAN1、反馈 ID `0x206`，Pitch 接 CAN2、反馈 ID `0x205`。两者使用 `0x1FE` 命令组：Yaw 占第二槽，Pitch 占第一槽。这是代码配置；电机固件及电流模式是否实际启用仍需在调试软件核对。

| 数据来源 | 已有内容 | 获取方式与限制 |
|---|---|---|
| 已发送的 USB 姿态包 | Yaw/Pitch 角、两个名为角速度的字段、四元数、模式字段 | PC 可直接保存原包和解码结果；具体含义见下一节 |
| INS 更新结果 | 连续 Yaw、Pitch/Roll、三轴陀螺、加速度 | MCU 已计算；需要新增导出点，不能从现有 USB 完整还原 |
| 控制目标与状态 | 最终接受的角度目标、手瞄/自瞄相关状态、停止标志 | 在控制类内部及状态更新位置取快照；目标成员不是现成的外部接口 |
| GM6020 CAN 反馈 | 编码器、转速、电流原始值、温度原始字节 | 接收回调已经解析；保存原帧及接收时间最便于复核 |
| 电机命令 | 控制输出的原始整数、CAN 发送分支实际提交的槽位值 | 两处分别记录；停止分支可能把输出改为零 |
| SMC 移植版诊断 | 参考、误差、滑模面、请求力矩、限幅、反馈年龄等 | 移植版内部已计算，尚未导出；旧 PID 工程没有这些 SMC 数据 |

### 已有 USB：可以立即留存，但要按真实含义使用

| 包内字段 | 实际来源 / 单位 | 分析时注意 |
|---|---|---|
| `yaw` | `INS.Yaw` 转 rad | 是回绕角，不是连续 `YawTotalAngle`；仅凭它不能可靠恢复有丢包的多圈运动 |
| `pitch` | `INS.Pitch` 转 rad | IMU 欧拉角，不自动等于折叠关节角或重力相位 |
| `yaw_vel` | `INS.Gyro[2]`，rad/s | 机体系陀螺 Z 轴，不在任意姿态下等于 Yaw 欧拉角导数 |
| `pitch_vel` | `INS.Gyro[0]`，rad/s | **旧 Pitch 控制使用的是 `Gyro[1]`**；不能按字段名直接当作 Pitch 速度 |
| `q[4]` | 经过 `ChangeQuat` 变换的四元数 | 相关注释对分量顺序不一致；先保存 `q0…q3` 和原包，再验证顺序与坐标系 |
| `mode` | 调用处的 `gimbalmode` 常量 | 不能用来判断实际是否进入自瞄，需另记实际控制分支 |

包内**没有 MCU 时间戳、设备序号、控制目标、电流或命令**。PC 可以新增接收时刻、本地包序号和 CRC 检查结果，但这些不等于 MCU 采样时间、设备发送序号或丢包计数。源码按云台任务调用次数间隔发送，任务调度和 USB 忙状态都会影响收到数据的间隔，不能当作严格等间隔采样。

先保存原始二进制包、解码脚本版本，以及 [USB 解码表](templates/test_data/usb_existing.template.csv)。调用处固定填写的弹速、发弹计数不能当作本次实验的测量结果。

## 2. 为控制器测试增加的最小记录点

沿用原控制与 CAN 路径，在以下位置复制小份快照，再由低优先级任务或 DMA 导出。避免在控制任务、CAN 中断里阻塞打印；具体导出频率由带宽和实测调度决定。

| 记录位置 | 建议保存的量 | 对应空白表 |
|---|---|---|
| 控制输入快照及输出确定处 | 本地时间、角度目标、连续 Yaw、Pitch/Roll、三轴陀螺、两轴原始控制输出、瞄准与停止状态 | [控制快照](templates/test_data/mcu_control_existing.template.csv) |
| CAN 接收回调 | 总线、ID、DLC、原始字节、本地接收时间；GM6020 可另存解码字段 | [通用原帧](templates/test_data/can_rx_raw.template.csv)、[GM6020 解码](templates/test_data/motor_rx.template.csv) |
| CAN 发送任务的各实际分支 | 提交时刻、总线、组 ID、四个槽位值、停止状态 | [GM6020 命令](templates/test_data/can_tx.template.csv) |
| 模式和参考来源切换处 | 实际手瞄/自瞄分支、停止/恢复、目标更新或丢失、实验阶段 | 可单独事件表；与控制快照共用 MCU 时钟 |

其中时间戳和日志序号是**需要新增的记录动作**。原工程可调用 `HAL_GetTick()` 取得毫秒时钟，但它表示软件记录时刻，分辨率不足以区分同一毫秒内的多个事件。若改用高分辨率时钟，先验证单调性、回绕和中断并发；不要复用控制器的 `DWT_GetDeltaT()` 计数变量，否则记录动作会改变控制周期计算。

各任务运行频率不相同。重复读取同一份 CAN/INS 缓存不是新反馈；需要在更新位置加接收/更新时间或序号，再随控制快照保存，才能判断陈旧数据。跨任务字段用一致快照或短临界区读取。保留时钟回绕、复位、记录溢出和缺包事件；原工程没有现成的日志丢弃计数，新增后才能报告它。

### 字段含义：避免名字造成误判

- `set_yaw_ / set_pitch_` 是控制类接受的目标，单位 deg。手瞄输入增量、视觉原始目标、限位后的目标是不同阶段，比较响应时应保留最终接受目标。
- `INS.YawTotalAngle` 是连续 Yaw，`INS.Pitch/Roll` 是欧拉角，单位 deg。`INS.Gyro[0..2]` 是机体系 rad/s。建议保存三轴陀螺及 Roll/Pitch，再按所用控制器的坐标变换生成角速度。
- `output_speed_[0/1]` 虽然名字包含 speed，实际是 `int16_t` 电机命令，**不是转速**。它还可能被发送任务的停止分支覆盖，所以需另记实际提交的 CAN 槽位。
- 电机 `GetCurrent()` 是有符号反馈原始值；`GetSpd()` 为协议转速 rpm；`GetAngle()` 为编码器累计角 deg。电流没有在旧解析层完成 A 或 N·m 标定，编码器角也不是 IMU 姿态或已标定的折叠关节角。
- 旧 `yaw_torque / pitch_torque` 是部分控制分支的请求量，不是反馈力矩，也不保证等于最终命令。进入 SMC 分支后，不应继续用这些旧 PID 中间量分析 SMC。

视觉目标需在成功接收时或视觉 PC 发出时保存原始位置/速度/加速度。旧工程在手瞄时会改写 `recepakge` 为同步值，稍后读取这个共享结构不能保证得到原始视觉输入。MCU 接收时间也不是相机曝光时间；曝光和处理时间只有视觉端确实提供时才能加入。

CAN 发送表记录的是软件提交值，不能据此宣称发送成功或电机已执行。旧发送包装没有向调用方保留 HAL 发送结果，也没有现成的发送失败、邮箱溢出、bus-off 统计；如果测试这些问题，需要另加状态记录。

## 3. SMC 移植版建议额外保存什么

在 `ControlSMC()` 的输入和结果仍有效时记录，而不是事后读取旧 PID 缓存。下列信息在移植版已计算，但仍需加入导出路径。

| 内容 | 实际取值位置 / 用途 |
|---|---|
| 输入目标与来源 | `input.ref_deg`、每轴 `vision_reference`；区分手瞄目标与视觉参考 |
| 控制器使用的参考 | `result.reference[axis]` 的角度、速度、加速度；手瞄参考生成后可能与角度目标不同 |
| 使用的反馈速度与前馈 | `result.rate_rad_s[axis]`、`result.feedforward_nm[axis]` |
| 误差与滑模面 | `result.smc[axis]` 的 `error_rad`、`rate_error_rad_s`、`sliding_rad_s`、`filtered_rate_rad_s` |
| 请求与限幅 | `torque_nm`、`unsaturated_torque_nm`、`flags`、`valid` 及 `result.command[axis]` |
| 反馈与模式资格 | 移植版增加的 INS/电机/视觉本地更新时间、反馈年龄、使能及停止状态 |

以上请求力矩仍是算法输出；`result.command` 之后还有保护分支和 CAN 发送路径。应保留最终提交值才能解释“控制器有输出，但电机没有动作”。标志位同时保存固件版本和位定义，SMC 状态、适配器返回值、辨识状态不要混成同一套 flags。

本仓库提供在线 RLS 模块，但该旧工程的 SMC 移植版**尚未接入 RLS**。候选参数、协方差、`ready`、拒绝原因不是当前已有遥测；将来接入后再记录。SMC 的 `valid` 也不等于该样本满足辨识条件。

接入在线模块后，可另记本次 `window_updated/ready`、候选 `model`、包装层与 RLS 各自的诊断、累计接受更新数，以及对应时间和构形。协方差采用模块的归一化回归坐标，不是物理参数置信区间。若应用了候选参数，还需保留切换时刻、前后参数版本、独立验证报告和回退事件，才能判断响应变化来自模型更新还是参考/工况变化。

## 4. 从这些数据到模型辨识，还缺哪一步

**当前 GM6020 原始电流日志可以帮助检查输出、延迟和跟踪表现；未标定时不能直接交给工具估计物理惯量。** 先核验对应固件的反馈电流比例，再校核转矩常数、外部传动、方向及时间对应关系，得到关节侧反馈力矩估计。命令电流的比例不能自动用于反馈电流；详见[电机协议](MOTOR_PROTOCOL.md)。

4310 的 MIT 包可以上报名义 N·m 力矩，省去 GM6020 原始反馈计数比例不明这一环，但它仍是电机驱动器报告值，需要校核比例、偏置、传动和时间，见 [DM4310 辨识步骤](DM4310_IDENTIFICATION.md)。两种电机都不能把 `applied_joint_nm` 或给定力矩当作实测反馈。

| 需要的量 | 旧工程目前的依据 | 处理方式 |
|---|---|---|
| 关节角及同坐标角速度 | IMU 姿态、机体系陀螺、电机编码器可用 | 固定底座，核对零位、方向和传动；连续 Yaw 用展开角，角速度按坐标关系变换 |
| 折叠 Pitch 重力相位 | 只有 IMU Pitch 和当前电机编码器等信息 | 固定工作位后标定几何；没有第二关节反馈时，不虚构折叠角或双关节状态 |
| 实际角加速度 | `INS.dGyro` 虽有声明，但没有实际更新 | 不作为反馈字段；现有积分辨识直接使用角速度增量，无需伪造加速度 |
| 同步反馈力矩 | GM6020 原始反馈值，或 4310 驱动器力矩报告 | 完成标定和时间对齐，保留原始值与转换脚本 |
| 饱和、使能和有效性 | 软件限幅、停止状态以及电机状态可部分判断 | 记录已知限制并判断资格；未知的内部限流不能填成“确认未饱和” |

固定底座、固定构形、固定负载，分别采集 Yaw/Pitch。折叠 Pitch 每个工作位分别建模型；两 Pitch 或大小 Yaw 先固定其他轴采集，联动与折叠过程不属于当前单轴模型的验证范围。记录构形可使用人工工作位编号与照片，不必假装已有折叠角传感器。

完成标定后，按[离线 CSV 的九列定义](IDENTIFICATION.md#3-最小侵入的日志接入)生成一轴一构形的训练文件与独立验证文件。原始日志保留原貌；工具输入必须时间严格递增、所有数值有限，布尔值严格写 `0/1`。无效、失能、饱和、缺包或状态切换要断开积分窗口，不能删除坏点后悄悄拼接。`segment` 只用于断窗，不能让不同构形在同一文件里自动分别拟合。

这里的[实验配置模板](templates/test_data/run.template.json)是采集说明，**不是**辨识工具 `--metadata` 输入。只有实际满足条件后，才在工具元数据中声明 `calibrated_feedback`、时间已对齐等资格；不要为了通过检查先填 `true`。

## 5. 每次实验怎么打包

建议一段完整实验建一个目录，用日期、轴、工作位和独立运行编号命名：

```text
run_<date>_<axis>_<configuration>_<number>/
  run.json                   实验配置、固件和参数版本
  raw/                       原始 USB/CAN/MCU 日志，不改写
  events.csv                 模式、启停、缺包、阶段与人工操作
  decode/                    解码脚本、字段/单位/时钟定义
  notes.md                   负载、折叠工作位、接线与实验现象
  analysis/                  派生 CSV、指标、图和候选报告
```

按本次实际实现的采集能力建文件，未实现项注明“未采集”，不要补造数据。至少保留以下配置：

- 固件 Git 提交或二进制 SHA-256、PID/SMC 构建选项、两轴参数与限幅快照、记录器和解码器版本。
- 电机型号/固件/模式、总线与 ID、反馈量程、角度零位和方向、外部传动；4310 另记 PMAX/VMAX/TMAX。
- 机构负载、底座固定方式、折叠工作位和目标行程；它们属于实验记录，不要求旧代码提供遥测。
- 每种时钟的单位与来源、记录频率、是否有反馈更新时间/丢弃计数、已完成的电流或力矩标定及转换版本。

| 实验 | 数据中应能定位的阶段 | 可检查什么 |
|---|---|---|
| 静止保持、双向小目标变化 | 原目标、新目标、保持段、方向 | 偏差、抖动、超调、稳态命令与 Pitch 支撑余量 |
| 手瞄、自瞄和互相切换 | 实际来源、接受目标、生成参考、切换时刻 | 参考连续性、跟踪误差、瞬时命令变化 |
| 连续 Yaw 跨圈 | 连续角、目标、原始编码器及阶段 | 回绕处理、跨圈跟踪；USB 回绕角单独不足以证明 |
| 折叠 Pitch 各固定工作位 | 工作位、负载、上下行方向与角度 | 重力/摩擦差异、方向不对称与限幅 |
| 辨识训练与独立验证 | 激励参考、合格反馈力矩、时间、状态 | 候选参数、验证残差、不同轨迹下的一致性 |

统计时声明时间区间、有效样本、角度单位和时钟。跟踪 RMS/峰值、限幅占比和丢弃计数只能对实际采集到的量计算。参数变化、温升、模式切换和反馈陈旧都应能回到原日志解释；截图和最终参数表不能替代原始记录。
