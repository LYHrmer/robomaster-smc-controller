# 文档导航

[返回项目首页](../README.md)

首次使用先从 [快速开始](QUICKSTART.md) 运行 C99 控制器。需要获取模型参数时，先选电机；已有标定参数时，可以直接按接入路线配置控制器。

## 先选电机：6020 还是 4310

| 使用的电机 | 专用采集与辨识指南 | 两者的主要区别 |
|---|---|---|
| **GM6020（6020）** | [GM6020 辨识](GM6020_IDENTIFICATION.md) | 保存电流原始计数，先核验反馈比例与力矩标定；包含双 GM6020 旧工程记录点 |
| **DM4310（4310）** | [DM4310 辨识](DM4310_IDENTIFICATION.md) | 保存 MIT 报告的位置、速度和力矩，先核对量程、状态与关节侧标定 |

每根轴按实际电机选一条路线；混用两种电机时分别核对。完成采集与标定后，两者共用离线/在线辨识工具，无需选择不同的 SMC 或 RLS 算法。

## 数据记录与通用辨识工具

**辨识**是用数据估计惯量、摩擦和重力等物理参数；它们与控制器增益不同。

| 阶段 | 文档 | 内容与适用范围 |
|---|---|---|
| 记录测试数据 | [数据清单与模板](TEST_DATA.md) | 旧工程字段以双 GM6020 为例；时钟、实验归档和资格要求两种电机共用 |
| 在电脑上分析合格日志 | [通用离线辨识](IDENTIFICATION.md) | 两种电机共用九列 CSV、独立训练/验证流程与候选 C 参数导出 |
| 在 STM32 上随新数据更新 | [通用在线拟合](ONLINE_IDENTIFICATION.md) | 两种电机共用 C99 递推最小二乘（RLS）接口及数据质量检查 |

“候选”表示参数仍需验证，尚未自动用于控制器。在线 `ready` 只表示本次数据满足候选条件；模型验证与参数切换由应用处理。当前云台辨识模型要求固定底座、固定构形和同步标定的力矩反馈。

## 查看验证证据

先看 [验证记录](VALIDATION.md) 中的构建结果与复现命令，需要细节时再打开对应报告。

| 文档 | 内容与范围 |
|---|---|
| [开源模型验证](OPEN_MODEL_VALIDATION.md) | 两份模型、576 个闭环组合、指标、门槛和复现方式 |
| [Pitch 专项验证](PITCH_VALIDATION.md) | 20 个验收场景和 4 个错误重力坐标诊断，包含上下行程与偏载 |
| [在线拟合验证范围](ONLINE_IDENTIFICATION.md#6-验证与适用范围) | RLS、流式积分与合成闭环程序的用途和限制；执行结果汇总在验证记录 |
| [原合成算例假设](../sim/assumptions.md) | 原始合成控制对照的参数、延迟、扰动和统计口径 |
| [开源参数审查](OPEN_SOURCE_PARAMETER_REVIEW.md) | 参数来源、可采用内容与不能作为辨识数据的部分 |
| [归档模型说明](../sim/open_models/README.md) | 固定版本原文件、许可、哈希与参数派生过程 |

CTest 的测试入口数与报告中的场景数分别计数。软件和合成模型结果不代表实机精度或三轴联动已经验证。
