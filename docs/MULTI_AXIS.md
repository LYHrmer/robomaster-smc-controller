# 多轴扩展方向

[文档导航](README.md) · [当前接入步骤](STM32_PORT.md) · [Pitch 整定](PITCH_TUNING.md)

**状态：设计方向，尚未实现三轴协调模块或完成三轴联动验证。** 当前可以复用的是单轴 C 控制核心与电机适配器。增加一个实例，需要同时解决机构坐标、参考分配、联合约束和动力学。

## 两种结构，分别分配任务

| 候选结构 | 建议的起点 | 新增难点 |
|---|---|---|
| 大 Yaw + 小 Yaw + Pitch | 大 Yaw 连续转动并接管慢变任务，小 Yaw 快速补偿；大轴帮助小轴保留双向行程 | 连续圈数、大小轴回中、速度/加速度互补分配、饱和后的任务调整 |
| Yaw + 折叠 Pitch + 瞄准 Pitch | 折叠轴先完成展开/收纳并保持工作位，Yaw 与末端 Pitch 承担瞄准 | 折叠状态机、联合几何约束、构形相关重力与惯量、到位后的参考接管 |

以上轴序只是设计示例。实际串联顺序、轴线、四连杆或传动约束决定具体运动学；两个电机驱动同一根关节时，问题又变为扭矩分担与同步。

## 在单轴核心上方增加协调层

```text
手瞄 / 自瞄指向目标 + 折叠 / 回中请求
                  ↓
机构模型、模式状态与约束处理
                  ↓
同一时刻的三轴角度 / 速度 / 加速度参考
                  ↓
各轴 SMC + 重力 / 耦合前馈
                  ↓
电机适配与统一 CAN 发送
```

手瞄、自瞄和折叠模块只提交请求，由一个协调器发布最终参考。各轴独立限速或裁剪后，必须重新检查末端任务是否仍成立。反馈、参考和发布结果还需要一致的时间与模式版本。

首版可在关节相对坐标下控制各轴，末端 IMU 用来反馈指向误差。每个独立关节要有能够建立零位和方向的反馈；不能让两根串联 Pitch 各自独立追同一个 IMU Pitch。

## 折叠 Pitch 的边界

折叠到位应由关节位置、速度和持续稳定共同判断；有机械锁止时还需相应证据。没有锁止证据时，只能按伺服保持处理。

外轴承担下游总成，保持力矩通常随折叠角、瞄准角和底座姿态变化，不能复制一条单 Pitch 重力曲线。运动学角度相加也只在特定平行轴假设下成立；即使朝向相同，相机位置和关节负载仍可能不同。

边折叠边瞄准需要额外验证整条路径的可达域、内轴行程、制动力矩和动态坐标变换。目标不可达时应明确拒绝或按模式降级，不能让控制器长期顶住限位。联合碰撞/线束约束也不能由三个独立角度区间完整表达。

## 连续大 Yaw 的边界

大轴内部保留连续角语义。世界指向的周期表示、手动多圈动作和编码器展开分别处理；选择等价目标时还要兼顾小轴行程。

长期运行可规划整圈整数基准与局部浮点坐标，统一平移反馈、目标和参考历史，避免大浮点角相减损失精度。该长期重基准机制属于后续协调设计，当前核心不会自动完成。

## 验证顺序

当前新增的[在线辨识模块](ONLINE_IDENTIFICATION.md)可以按轴、按固定构形各自保存参数与估计状态。折叠过程中应中断当前积分窗口；展开后确认构形与负载匹配，再恢复对应实例。它不会自动识别折叠状态，也不会从单轴回归得到完整耦合模型。

1. 核对轴序、编码器零位、安装变换、机械行程及联合允许区域。
2. 验证正运动学、参考分配和折叠状态机，分别记录原始目标与末端指向误差。
3. 用实际 C 代码运行耦合动力学模型，包含构形变化、重力、饱和、延迟与故障。
4. 完成目标 STM32 的构建、最坏时序与 CAN 更新偏差测量，再分阶段上机。

三轴扩展的验证不能由三份单轴测试代替。当前已完成的范围见 [验证记录](VALIDATION.md)；通用 C 核心的接口保持每实例独立，方便后续机构协调层复用。
