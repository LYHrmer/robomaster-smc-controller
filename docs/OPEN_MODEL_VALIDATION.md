# 基于开源云台模型的仿真验证

本轮在两份可追溯的开源机器人模型上提取四个云台关节参数，实际调用本仓库 C 控制器、电机适配器与 CAN 字节打包，再独立解码给定力矩，完成 **576 个闭环组合**。这是开源模型支持的合成仿真，尚无本项目的实机或 STM32 时序测量。

## 1. 参数来源与采用范围

| 开源模型 | Yaw 等效惯量 kg·m² | Pitch 等效惯量 kg·m² | Pitch 重力保持力矩 G(q)，N·m |
|---|---:|---:|---|
| [RMOSS RMUA19](https://github.com/robomaster-oss/rmoss_gz_resources/blob/20530be7afda1c6a15cab90a46706aa58463acba/resource/models/rmua19_standard_robot/model.sdf) | 0.00608000833333 | 0.004898175 | −0.220725 cos(q) |
| [DynamicX Standard3](https://github.com/rm-controls/rm_description/blob/a4b31828bf964e491d3ba5a731d12c1213562feb/urdf/standard3/standard3.urdf.xacro) | 0.00713692704547 | 0.00975136641445 | −0.454831759840 sin(q) −0.361892836604 cos(q) |

两者均以底座固定、其它关节锁定在零位求单轴标量模型。RMOSS 是依据官方机器人资料建立的社区几何近似模型；DynamicX 是其开源机器人描述。它们不是这两台待部署电机的实测负载，不意味着原机器人安装了本次模拟配置的电机。

Pitch 使用源模型硬限位：RMOSS `[-0.785,0.5652] rad`，Standard3 `[-0.72,0.457] rad`。Yaw 测试采用自定的 `[-0.5,0.5] rad` 验证区间，不把它说成实机机械限位。每个控制拍以及每个 0.1 ms 积分子步均检查真实关节角界。

惯量由完整转动子树的质量、重心、张量与安装变换计算：

\[
J=\sum_i \left[a^T R_i I_i R_i^T a
+m_i\left(\|r_i\|^2-(a^Tr_i)^2\right)\right].
\]

这里 `a` 为轴单位向量，`r_i` 是从该转轴原点到部件质心的向量。相机、IMU、测速模块或摩擦轮是否计入，由源模型的父子连接关系决定；不能见到零件名称就不加区分地并入云台。

Standard3 源模型中 `camera_optical_frame` 的极小惯性张量不是半正定。提取脚本保留其 1 g 质量和安装位置，显式采用点质量近似将该虚拟坐标系的转动张量置零；原始文件保持不变，更正记录在 `details.json`。这是已说明的模型处理，不能包装为无修改的实测惯量。

原始文件、上游许可、固定 commit、Git blob SHA、SHA256 和每个部件的计算明细均在 [参数归档](../sim/open_models/README.md)。离线复算：

```sh
python3 tools/derive_open_model_profiles.py --check
```

仅依赖 Python 标准库，无需下载 ROS、Gazebo 或网格文件。该脚本针对归档模型的受限语法，不是通用 Xacro/SDF 解析器。

## 2. 验证矩阵

组合数为 `4关节 × 2电机 × 3采样率 × 3惯量倍率 × 2参考 × 2控制器 × 2重力前馈系数 = 576`。

| 维度 | 设置 |
|---|---|
| 电机协议 | DM4310 MIT / GM6020 已启用原生电流模式 |
| 控制频率 | 500、1000、2000 Hz |
| 实际惯量 | 来源名义值的 0.5、1、2 倍；控制器仍使用名义值 |
| 参考 | 恒位保持，初始偏差 0.03 rad；0.1 rad 峰值、0.5 Hz 解析正弦 |
| 控制器 | 默认线性面；增加 `alpha=1.5,r=0.5,delta=0.01` 的正则化终端面 |
| 重力前馈 | 源模型精确系数的 1.0、0.8 倍 |
| 每组合时长 | 6 s；0.1 ms RK4 植物模型积分 |

共同控制参数为 `lambda=12/s, k=10/s, eta=20 rad/s², phi=0.1 rad/s`，速度低通 80 Hz，输出变化率限幅关闭。本轮没有因结果不同而单独改变某个模型/电机的增益或验收门槛。

加入下列**自定测试假设**：1 ms 命令延迟、3 ms 执行器一阶滞后、`B=0.01 N·m·s/rad` 粘性阻尼；2 s 起施加 `−0.03+0.02 sin[2π·1.3·(t−2)] N·m` 扰动。角度纹波幅值为 `0.0001[sin(2π31t)+0.5sin(2π73t)] rad`；速度纹波为 `0.002[sin(2π43t)+0.5sin(2π91t)] rad/s`。它们未从开源模型辨识，不是实测噪声谱。模型中的库仑摩擦参数没有直接并入本次粘性近似。

动力学约定为 `J*qdd = tau_actual − B*qdot − G(q) + d`，所以保持补偿为 `+G(q)`，物理重力外力矩是 `−G(q)`。前馈使用真实模型角度，1.0 系数是理想辨识条件，0.8 是预先设置的补偿偏差测试。

两种电机均采用直连、外部传动比 1、效率 1 和 **±1 N·m 应用限制**。DM 仿真选用 `PMAX=12.5,VMAX=30,TMAX=10` 协议范围，GM 采用 `Kt=0.741 N·m/A` 与相应电流限值；这是本轮明确选择的适配配置，不能据此断言任意固件都使用相同量程，或把应用限制当作实测连续额定能力。

DM 力矩先组 MIT 字节再独立解码；GM 先转换电流、组四槽 CAN 帧，再从字节恢复有符号电流与力矩。没有直接把适配器的 `applied_joint_nm` 返回值当作独立验证。仿真包含给定量化，仍没有实际 CAN 仲裁、丢包、FOC、电压饱和、温升或硬件反馈量化。

## 3. 验收门槛与结果

运行前固定的门槛为：`t>=1s` 窗口内位置 RMS `<0.02 rad`、位置峰值误差 `<0.06 rad`；无非法控制状态、非有限值、实际报文/执行器力矩越限或真实关节角越界。该窗口保留 2 s 负载扰动及其恢复，不能称为纯稳态窗口。

若参考逆动力学的采样需求力矩已超出电机量化后的可用能力，或参考超出关节区间，预检单列 `INFEASIBLE`；不计为通过，也不运行闭环。预检通过仅是必要条件筛查，运行阶段继续按相同门槛检查，失败保留 `FAIL`。

本轮结果：**576 PASS，0 FAIL，0 INFEASIBLE**。全部组合中：

| 指标 | 最差或最大值 |
|---|---:|
| 1 s 后窗口位置 RMS | 0.003161458 rad（约 0.181°） |
| 1 s 后窗口位置峰值误差 | 0.005400267 rad（约 0.309°） |
| 独立解码后的给定力矩绝对峰值 | 0.673928284 N·m |
| 控制器幅值饱和比例 | 0 |

不同指标的最坏值来自不同组合，完整条件保留于 [逐组合指标](../sim/results/open_model_metrics.csv)。正则化终端面增加了有效反馈增益，部分组合误差更低，但输出总变化量增加；最高给定总变化量/时长约为 41.78 N·m/s，不能只看 RMS 就称抖振更小。两种方案未做等带宽整定，因此本轮支持软件回归和参数适应性判断，不构成终端滑模的普遍性能优势证明。

代表曲线每 10 个控制拍记录一次（100 Hz），只保留名义惯量、1 kHz、完整重力补偿组合，用于观察跟踪形态；所有验收指标用全控制频率计算。稀疏曲线不能用来估计高频抖振。

## 4. 复现

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
# CTest 已生成 build/open_model_metrics.csv 和 build/open_model_trace.csv。
python3 sim/plot_open_models.py \
  build/open_model_metrics.csv build/open_model_trace.csv sim/results/open_models
```

绘图需要 Matplotlib。无 GUI 的开发环境使用 Agg 后端。源模型哈希与派生参数复核也已加入 CTest；缺少 Python 时不会注册该项，发布验证及 GitHub CI 使用有 Python 的环境。

矩阵验证器退出码：0 表示全部通过，1 表示输入/I/O/运行失败，2 表示存在不可行组合且无其它失败。另用无效输入、超过力矩能力、失稳假模型检查过负路径，确保不会把未运行的情况记成通过；未运行性能字段写为 NaN。

## 5. 上机结论的边界

本轮采用固定姿态下的单轴等效惯量，冻结另一轴及附属活动部件，没有求解完整多体耦合；摩擦轮旋转的陀螺效应、底盘运动、柔性、间隙和传感器坐标误差仍待实际系统验证。模型惯量倍率扫描也不等价于严格证明这些误差全部被覆盖。

可据此发布控制器源码和复现材料。部署到自己的云台仍需使用自己的电机配置、负载参数、坐标与安全状态机，完成 STM32 编译/时序及电机台架验证；上述角度误差不是实机精度承诺。
