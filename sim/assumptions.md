# 合成仿真与回归边界

本目录全部曲线为 **synthetic / demo 合成数据**。`simulate.c` 实际调用 `src/gimbal_smc.c`，用于核对闭环行为、采样率适应和改进方案的取舍。模型未经云台或电机辨识，不代表 GM6020、DM4310 或参赛机器人的实测性能，也不是 STM32 执行时间测试。

## 运行

在工程根目录执行：

```bash
cmake -S . -B build
cmake --build build
./build/simulate build/simulation.csv
python3 sim/plot_results.py build/simulation.csv --output-dir sim/results
```

开发主机已验证的绘图解释器为 `/usr/bin/python3 -s`（Matplotlib 3.5.1），可用它替换最后一行的 `python3`，避免用户目录 NumPy 环境冲突。无需修改系统 Python。绘图代码使用标准库 `csv` 与 Matplotlib，不依赖 pandas。

仿真将完整闭环记录写入指定 CSV，并把独立差分诊断写入 `<trace.csv>.derivative.csv`；标准输出提供指标和 PASS/FAIL，总回归失败时进程返回非零。绘图生成三组 PNG/SVG 和可再次分析的 `metrics.csv`。

## 动力学、单位与数值方法

连续单轴模型为：

\[
\dot\theta=\omega,\qquad
J\dot\omega=\tau_a-B\omega+d(t).
\]

其中角度为 rad，速度为 rad/s，力矩为 N·m，惯量为 kg·m²。正指令增加正方向角速度。控制器输出表示被控轴处的目标力矩，仿真没有 CAN 量化、力矩常数或电机固件协议换算。

部分工况引入命令延迟和执行器一阶动态：

\[
T_a\dot\tau_a=\tau_c(t-T_d)-\tau_a.
\]

采用 0.1 ms 固定子步 RK4 积分。控制器以 500/1000/2000 Hz 零阶保持输出；延迟队列按积分子步推进。因此跨采样率比较时，1 ms 延迟保持不变，不会误变成“一个控制周期”。名义理想执行器工况令实际力矩直接等于当前指令。初始角速度、实际力矩及延迟队列均为零。

反馈角度/速度取当前真实状态后添加指定测量纹波；反馈时延为零、`feedback_age_s=0`，没有模拟陈旧反馈或丢包。命令延迟与反馈数据年龄是两回事。

## 控制器参数

两种方案均使用当前 C 核心。`linear` 令终端增益为零；`regularized_terminal` 令其为 1.5。共同参数为：

| 参数 | 数值 |
|---|---:|
| 名义惯量 Ĵ | 0.01 kg·m² |
| 名义粘性阻尼 B̂ | 0.01 N·m·s/rad |
| λ / k / η | 12 s⁻¹ / 10 s⁻¹ / 20 rad/s² |
| 边界层 φ | 0.1 rad/s |
| 终端指数 r / 正则化 δ | 0.5 / 0.01 rad |
| 力矩限幅 | ±0.5 N·m |
| 角速度一阶低通 | 80 Hz，首拍以实际量测初始化 |
| 力矩变化率限幅 | 关闭 |
| 额外负载/重力前馈 | 0 |
| 角度回绕 | 关闭 |

这些均为合成算例参数，不是两种电机的推荐上车值。终端方案在相同 λ、k 等参数外增加了状态相关增益：原点附近滑模面斜率从 12 增至 27 s⁻¹，因而本比较**没有匹配两者的局部带宽或噪声放大率**。它可以展示这一配置组合的行为，不能证明终端滑模相对所有已整定线性控制器普遍更优。

## 四类工况，共十二条闭环

| 工况 | 采样率 | 实际 J / B | 初始角度 | 参考与负载 | 执行器与反馈 |
|---|---|---|---|---|---|
| hold_load | 1000 Hz | 0.01 / 0.01 | 0.35 rad | 目标 0；2 s 时负载变为 −0.06 N·m；运行 5 s | 理想执行器，无噪声 |
| sine_tracking | 1000 Hz | 0.01 / 0.01 | 0 rad | 0.25 rad、0.7 Hz 正弦；无外负载；运行 6 s | 理想执行器，无噪声 |
| heavy_disturbance | 1000 Hz | 0.02 / 0.015 | 0.35 rad | 目标 0；2 s 起 −0.06 + 0.02 sin[2π·1.3·(t−2)] N·m；运行 5 s | 1 ms 延迟、3 ms 一阶动态、测量纹波 |
| sample_rate | 500/1000/2000 Hz | 0.01 / 0.01 | 0 rad | 同一 0.25 rad、0.7 Hz 正弦；2 s 起 −0.04 N·m；运行 6 s | 同一 1 ms 延迟、3 ms 一阶动态、测量纹波 |

每个组合分别运行 linear 和 regularized_terminal。正弦参考的位置、速度、加速度来自同一解析函数，均显式传入核心；初始机构速度仍为零，允许并保留启动跟踪瞬态。恒位工况使用初始位置偏差，不将参考阶跃的形式导数假装为有限加速度。

测量纹波是确定性带限测试信号，不是实际传感器噪声谱：

\[
n_\theta=10^{-4}[\sin(2\pi31t)+0.5\sin(2\pi73t)]\ \mathrm{rad},
\]
\[
n_\omega=0.002[\sin(2\pi43t)+0.5\sin(2\pi91t)]\ \mathrm{rad/s}.
\]

不同控制器和不同采样率在相同物理时刻面对相同纹波。没有模拟结构柔性、齿隙、库仑摩擦、供电波动、热限制、IMU 坐标误差、底盘运动耦合或真正的电机电流环。

## 指标与判据

- RMS、峰值和 IAE 使用真实机构位置减参考，避免把注入的测量噪声直接当作真实跟踪误差。
- 同时报告全时段指标和 `t≥1 s` 的 RMS/峰值；后者剔除初始恢复，但保留 2 s 负载突变及其恢复。
- `saturation_ratio` 为核心报告幅值限幅的控制拍数占比。指令峰值上限为 0.5 N·m。
- `command_total_variation_nm_s` 为 `Σ|τc[k]−τc[k−1]| / duration`，包含从零指令启动的第一步，也包含正常跟踪所需力矩变化；**不等同于抖振频谱或振动幅值**。
- C 标准输出的 `final_error_rad` 使用最后一次积分后的 `t=duration` 状态。绘图重算的汇总不包含该项，因为原始 CSV 最后一条记录在 `duration−dt`。

运行前设定的回归包络为：无控制器故障、所有指令不超过 0.500001 N·m、位置绝对值不超过 2 rad、角速度不超过 20 rad/s；`t≥1 s` RMS 小于 0.015 rad、峰值小于 0.05 rad；恒位工况最终误差小于 0.01 rad。这些是捕捉符号、单位、异常数值和明显不收敛的宽松代码回归条件，不是赛事精度验收标准。

当前参数组合的终端方案通常有更小位置误差，但额外增益也提高输出变化量；在带延迟与纹波的 500 Hz 工况尤为明显。请同时查看误差与力矩曲线，不仅比较单一 RMS。实机是否改用终端项应由噪声、结构共振和跟踪要求共同决定。

## 原开源目标差分的独立诊断

参考 [xinruilee04/smc_controller](https://github.com/xinruilee04/smc_controller/blob/main/SMC/slidingmodec.cpp) 的目标历史更新约定，仅建立一个 10°、1 Hz 正弦目标的差分实验：

- `native_rate_used_raw` 是上拍目标增量，保留“先使用旧导数，再更新目标增量”的时序；它的单位为 °/sample。
- `native_accel_raw` 是相邻目标增量之差，单位为 °/sample²。
- 同时计算本拍除以 dt 的后向一阶差分、再次除以 dt 的二阶差分，并与解析 °/s、°/s² 对照。
- 每种采样率从指标中排除最初两拍不可用历史，完整启动数据仍写入 CSV。

标准输出中将 raw 数值与物理导数相减，仅用于量化“把 raw 数值按原说明当作 °/s 或 °/s² 使用”时的数值偏差；这些 raw 列本身不具有相应物理导数单位。图中将它们分开坐标标注，避免隐含单位相同。

此实验未复现原控制律、输出映射、死区分支或原队机构，不得据此评价原队实战效果。它也没有覆盖原版提前返回导致的历史停止更新，只隔离目标差分单位和使用时序问题。
